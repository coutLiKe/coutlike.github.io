PassGuard — Password Security Analyzer

A browser-based password security tool that calculates Shannon entropy and estimates crack times across multiple attack scenarios — including online throttled attacks, offline bcrypt, MD5, and GPU cluster brute force. Built following NIST SP 800-63B guidelines with a real-time security checklist detecting common passwords, keyboard sequences, and character repetition patterns. Engineered entirely client-side — user passwords are never transmitted or stored.

PhishGuard — Phishing URL Detector

A URL threat analysis tool that runs 17 detection checks against real-world phishing techniques documented in MITRE ATT&CK (T1566) — including homoglyph substitution, brand impersonation, subdomain spoofing, open redirect parameters, and high-risk TLD identification. Implements homoglyph normalization to catch typosquatted domains like paypa1.com and a brand-in-subdomain check for patterns like paypal.com.evil.tk. 005
TicketDesk — IT Help Desk & Asset Tracker

A full-stack help desk where requesters file tickets, technicians work them through open → in_progress → resolved, and admins manage users — with laptops, monitors, and phones tracked as assets that link to tickets. Role-based access control is enforced server-side on every endpoint and tested per role, including refusal cases; hidden records return 404 instead of 403, and roles are re-read from the database on each request so deactivated users are locked out instantly. Technicians get internal notes requesters never see. Backed by 322 backend tests (97% coverage) against real PostgreSQL migrations, with CI and Docker, deployed on Render, Neon, and GitHub Pages.

006
Endpoint Triage — Help Desk Diagnostics CLI

A cross-platform, read-only command-line tool a technician runs with one command on macOS, Windows, or Linux to collect system, disk, network, VPN, proxy, and pending-update diagnostics — then writes a ticket-ready .txt and versioned .json report with CRITICAL / WARNING / INFO findings and Nagios-style exit codes for RMM monitors. Ping, DNS, and TCP 443 tests are combined to pinpoint the likely fault: local network, DNS, firewall, proxy, or internet path.
